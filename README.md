# Company Policy AI Assistant

An AI-powered question-answering application using Retrieval-Augmented Generation (RAG).

## Technologies

- Python
- LangChain
- OpenAI
- Sentence Transformers
- Semantic Search
- RAG

## Example Questions

- How many vacation days do employees receive?
- Can employees work remotely?
- What insurance benefits do employees receive?
- Do employees receive dental and vision insurance?
- How early should I request vacation?

## Project Goal

The application allows employees to ask questions about company policies and receive answers based on the provided company documents.

## Current Status

Currently developing the RAG chatbot and preparing it for deployment.
